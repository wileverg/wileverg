## 🧑‍💻 Instructions for AI Agents

1. **Understand the user's profile**: Ask for their name, role, tech stack, experience, and key achievements.
2. **Select a template style** from the categories above based on their personality:
   - Designer/Creative → Elanza-48, Adam-pw, Parply
   - Backend/Full-stack Dev → DenverCoder1, 10kartik
   - Data Scientist → Kaustav, MaartenGr
   - Open Source contributor → FahimFBA
   - Neutral/Any → JayantGoel001, Josuerv99
3. **Use `profile_template.md`** as the structural base, filling all `YOUR_*` placeholders.
4. **Mix in feature widgets** from the "Feature-Specific" table above if the user requests them.
5. **Always apply the wileverg standards**: JSON-LD SEO block, bilingual option, STAR/PAR metrics, skill icons from `skillicons.dev`.
6. **Never output `YOUR_USERNAME` or any other unresolved placeholder** in the final README.
