## 🛠 Tech Stack | Tecnologías

My architecture prioritizes scalability, cross-platform reach, and SEO
optimization.

*Mi arquitectura prioriza la escalabilidad, el alcance multiplataforma y la*
*optimización SEO.*

* **Frontend:** Flutter (Mobile, Desktop, Web) for unified experiences, and
  Next.js/React for SEO/LLM-friendly web applications.
  *(*Flutter para experiencias unificadas y Next.js/React para webs optimizadas*
  *para SEO y LLMs.*)*
* **Backend:** Supabase (PostgreSQL, Auth, Realtime) for scalable flat-rate
  database solutions, alongside Firebase for its free-tier features. Node.js &
  Express handle edge computing.
  *(*Supabase para bases de datos escalables, junto con Firebase. Node.js y*
  *Express para edge functions.*)*
* **Cloud & Tooling:** Cloudflare for robust web security and CDN. My workflow
  is heavily powered by Claude Code + MCPs, Antigravity IDE, Gemini CLI, and
  GitHub Pro.
  *(*Cloudflare para seguridad y CDN. Mi flujo de trabajo está potenciado por*
  *Claude Code, Antigravity IDE y GitHub Pro.*)*
